Hapus Background Music dari Audio Video Secara Real-Time

Tool open-source untuk memisahkan dan meredam musik latar dari video (seperti YouTube) sehingga hanya menyisakan suara bicara/vokal. Tersedia dalam bentuk Chrome Extension yang langsung jalan di browser, serta Python CLI untuk memfilter seluruh audio Windows.

Download Chrome Extension (.zip - 6.9 MB) Lihat Source Code di GitHub

Cara Pasang Chrome Extension

Versi Chrome Extension memfilter suara per-tab langsung di dalam browser tanpa perlu menginstal Virtual Audio Cable atau menjalankan Python.

  1. Download file music-remover-chrome-extension.zip lalu extract (unzip) ke folder di komputermu.
  2. Buka halaman chrome://extensions di Google Chrome, lalu aktifkan Developer mode di pojok kanan atas.
  3. Klik tombol Load unpacked di pojok kiri atas, lalu pilih folder chrome_extension hasil extract tadi.
  4. Buka tab YouTube atau video yang ingin difilter, klik icon Music Remover di toolbar Chrome, pilih model, lalu klik Start on This Tab.

Catatan untuk developer: Jika kamu melakukan git clone dari repositori, jalankan python setup_extension.py terlebih dahulu untuk mengunduh file runtime WebAssembly dan model ONNX ke dalam folder chrome_extension/.

Trade-Off & Perbandingan Model

Memisahkan musik dari vokal secara real-time punya kompromi antara kualitas suara, jeda waktu (delay), dan beban CPU/GPU. Berikut hal yang perlu kamu ketahui sebelum memilih model:

1. Beban Browser (Kenapa Chrome Bisa Nge-Lag di Model Berat?) Model pemisah musik murni seperti Kim Vocal 2 dan Voc_FT (~64 MB) punya komputasi yang berat. Di laptop tanpa GPU dedicated (hanya Integrated GPU / iGPU), menjalankan model sebesar ini di dalam browser (WebGPU/WASM) akan berbagi resource dengan proses rendering halaman Chrome. Jika browser terasa patah-patah, gunakan model GTCRN di extension, atau jalankan Kim Vocal 2 lewat versi Python CLI.
2. Delay Suara vs Gambar Video (Lip-Sync) Model MDX-Net (Kim Vocal 2 & Voc_FT) butuh menabung audio selama beberapa detik (Chunk Delay 1.5s – 5.9s) agar bisa memisahkan pola instrumen musik dari vokal dengan bersih. Semakin besar delay yang diatur, semakin ringan kerja CPU—tetapi suara akan terdengar beberapa detik lebih lambat dibanding gambar di video.
Model Tersedia Di Hasil Pemisahan Musik Sample Rate Delay Beban Perangkat
GTCRN
gtcrn_simple.onnx (523 KB)		 Chrome Extension Sedang (fokus hapus noise & BGM tipis; musik ramai masih bisa bocor) 16 kHz (kualitas telepon) ~20 – 60 ms (video & suara tetap sinkron) Sangat ringan. Lancar di semua laptop langsung di browser.
Kim Vocal 2
Kim_Vocal_2.onnx (63.7 MB)		 Chrome Extension & Python CLI Sangat bersih. Model khusus isolasi vokal (MDX-Net), musik hilang hampir total. 44.1 kHz 1.5 – 5.9 detik (saran CPU: 4.5s – 5.5s) Berat. ~3.3 detik/chunk di Python CLI (CPU). Di browser butuh PC kencang/GPU.
UVR-MDX-NET Voc_FT
UVR-MDX-NET-Voc_FT.onnx (63.7 MB)		 Chrome Extension & Python CLI Paling natural. Pemisahan musik bersih dengan warna vokal lebih utuh. 44.1 kHz 4.5 – 5.9 detik Paling berat (~2x Kim). ~6.8 detik/chunk di CPU-only. Disarankan pakai GPU.
DeepFilterNet3
PyTorch		 Python CLI Bagus (deep filtering + High-Pass 120Hz pemotong bass) 48 kHz (suara bicara paling tajam) 0.5 – 5.0 detik Menengah. Lancar dijalankan di CPU lewat Python CLI.
DTLN
dtln_1/2.onnx (3.9 MB)		 Python CLI Cukup untuk mereduksi musik latar sederhana 16 kHz ~70 – 150 ms Sangat ringan di CPU spek rendah.

Opsi Tambahan: Versi Python CLI (Windows Desktop)

Versi Python CLI menangkap seluruh audio Windows (WASAPI Loopback) dan berjalan di atas ONNX Runtime C++ native multi-core. Opsi ini jauh lebih ringan dan stabil jika kamu ingin memakai Kim Vocal 2 di laptop tanpa dedicated GPU, atau ingin memfilter suara dari aplikasi selain Chrome (VLC, Zoom, Media Player).

Cara Menjalankan

Di Windows, kamu bisa langsung klik dua kali file run_python.bat, atau jalankan lewat terminal: 

pip install -r requirements.txt
python music_remover.py

Contoh Perintah Langsung

# Menjalankan Kim Vocal 2 dengan delay 5 detik:
python music_remover.py --engine kimvocal --delay 5.0 --output "Headphones" --latency

# Menjalankan UVR-MDX-NET Voc_FT:
python music_remover.py --engine vocft --delay 5.5 --output "Headphones"

# Menjalankan DeepFilterNet3 (48kHz):
python music_remover.py --engine deepfilter --delay 2.0 --post-filter
