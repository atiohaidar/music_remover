Opsi Lain: Chrome Extension (Langsung di Tab YouTube)

Kalau malas download file videonya dulu dan ingin langsung memfilter suara tab browser secara "real-time", pasang Chrome Extension-nya (tanpa VB-Cable atau backend Python).

Download Chrome Extension (.zip - 6.9 MB) Lihat Source Code di GitHub
  1. Download file music-remover-chrome-extension.zip lalu extract (unzip) ke folder di komputermu.
  2. Buka halaman chrome://extensions di Google Chrome, lalu aktifkan Developer mode di pojok kanan atas.
  3. Klik tombol Load unpacked di pojok kiri atas, lalu pilih folder chrome_extension hasil extract tadi.
  4. Buka tab YouTube atau video yang ingin difilter, klik icon Music Remover di toolbar Chrome, pilih model, lalu klik Start on This Tab.

Catatan untuk developer: Jika kamu melakukan git clone dari repositori, jalankan python setup_extension.py terlebih dahulu untuk mengunduh file runtime WebAssembly dan model ONNX ke dalam folder chrome_extension/.

Trade-Off & Perbandingan Model

Memisahkan musik dari vokal punya kompromi antara kualitas suara, jeda waktu (delay di mode live), dan beban CPU/GPU. Berikut hal yang perlu kamu ketahui sebelum memilih model:

1. Proses File (di atas) vs Live Chrome Extension Di mode Proses File di atas, seluruh durasi file diproses terlebih dahulu sebelum diputar ulang. Sedangkan di mode Chrome Extension (Live Tab), pemrosesan dilakukan sambil video berjalan sehingga model berukuran besar seperti Kim Vocal 2 dan Voc_FT (~64 MB) dapat membebani CPU/GPU pada perangkat tanpa dedicated GPU. Untuk beban komputasi lebih rendah tersedia opsi GTCRN (523 KB) atau Python CLI.
2. Delay Suara vs Gambar Video di Mode Live (Lip-Sync) Saat memakai Chrome Extension atau Python CLI dengan model MDX-Net (Kim Vocal 2 & Voc_FT), model mengumpulkan potongan audio selama beberapa detik (Chunk Delay 1.5s – 5.9s). Semakin besar nilai delay, frekuensi inferensi per detik berkurang—namun suara akan terdengar beberapa detik lebih lambat dibanding gambar video.

Opsi Tambahan: Versi Python CLI (Windows Desktop)

Versi Python CLI menangkap audio sistem Windows (WASAPI Loopback) dan berjalan di atas ONNX Runtime C++ native multi-core. Opsi ini dapat digunakan untuk menjalankan model secara live lewat terminal atau memfilter suara dari aplikasi selain Chrome (VLC, Zoom, Media Player).

Cara Menjalankan

Di Windows, kamu bisa langsung klik dua kali file cli/run_python.bat, atau jalankan lewat terminal dari folder cli/: 

cd cli
pip install -r requirements.txt
python music_remover.py

Contoh Perintah Langsung

# Menjalankan Kim Vocal 2 dengan delay 5 detik:
python music_remover.py --engine kimvocal --delay 5.0 --output "Headphones" --latency

# Menjalankan UVR-MDX-NET Voc_FT:
python music_remover.py --engine vocft --delay 5.5 --output "Headphones"

# Menjalankan DeepFilterNet3 (48kHz):
python music_remover.py --engine deepfilter --delay 2.0 --post-filter
